# Spectrum

A visual and interactive audio visualization project built with **p5.js** and **p5.sound**.

## 🚀 Overview

`spectrum` utilizes the p5.js library alongside its sound module to process audio input or sound files and create responsive, generative graphics. It is hosted directly on GitHub Pages for easy access and viewing.

## 📁 Repository Structure

```text
├── index.html       # Main HTML entry point
├── sketch.js        # p5.js visual and audio logic
├── style.css        # Custom page styling
├── p5.js            # Core p5.js library file
└── p5.sound.min.js  # p5.sound extension library
